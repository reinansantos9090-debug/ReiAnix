# ReiAnix monetization

- All variants (PR, debug, benchmark, official APK and AAB) use the real Google integrations. No simulated Premium, hardcoded demo price, demo ads or reset button exists. Old demo entitlements are ignored; verified receipts and real rewarded unlocks use the existing production preferences.
- Create and activate the non-consumable one-time product `reianix_premium` in Play Console, set the Brazil base price to R$ 9.90, then copy the app's RSA billing public key to GitHub Settings > Secrets and variables > Actions > Variables > `REIANIX_BILLING_PUBLIC_KEY`. This is the public licensing key, not the private signing key. The APK/AAB workflow reads the public variable automatically on main and PRs. Missing key leaves purchases unavailable rather than simulating them; an invalid key fails the build.
- Build and upload a new signed AAB from main. Test through a Play internal/closed track with license testers and Google test payment methods; real BillingClient integration does not mean testers must pay. Price comes from Play. Do not consume the product.
- Five real AdMob placements are configured and enabled by default in every build. Complete applicable AdMob review, UMP consent messages, app-ads.txt, privacy policy, Data Safety and rights checks before public distribution. Requests remain subject to UMP consent and AdMob eligibility/fill; enabling requests does not guarantee delivery. The optional Actions variable `REIANIX_ENABLE_LIVE_ADS=false` can explicitly pause requests; remove it or set it to `true` to resume. No sample IDs or simulated rewards are used. Register development devices as test devices in AdMob and never click live ads.
- Real purchases are verified locally using Google's RSA signature and acknowledged; purchases are queried on foreground to recover/refund state. Client-only verification is not tamper-resistant; secure backend verification is recommended before public monetization.
- No ads in the player. Existing Premium benefits, local library and playback are unchanged. DAY rewards grant temporary Premium for 24h; art rewards remain local. Old simulated entitlements never migrate.
- Local builds: `-PreianixBillingPublicKey=<public key>`; ads are on by default, with optional `-PreianixEnableLiveAds=false` to pause them. For development use Google's official license testers and registered AdMob test devices. PR APKs remain debug-signed; actual purchases depend on Play eligibility and installation/signing requirements. No signing credentials are exposed to PRs.
- Verify real purchase, restore, cancellation, pending purchase, refund, consent, no-fill, offline, restart and expiry on-device before public distribution.
